Consumes less than 0.31ms per frame (< 2% of a 16.6ms 60 FPS frame), leaving 98% of the CPU budget for games/apps.

Achieves < 1.81° angular gaze error across the standard MPIIGaze dataset.

Integrated SIMD Kalman state filter eliminates high-frequency pupil tremor without introducing lag.
